# Matugen theme

Ryujinx can follow a palette generated by [Matugen](https://github.com/InioX/matugen).
Matugen remains responsible for selecting the wallpaper, Material You scheme, and
light/dark mode. Ryujinx watches the generated XAML and applies valid changes live.

## Setup

1. Copy `docs/matugen/ryujinx.xaml` to Matugen's template directory.
2. Add a template entry to `~/.config/matugen/config.toml`, for example:

   ```toml
   [templates.ryujinx]
   input_path = '~/.config/matugen/templates/ryujinx.xaml'
   output_path = '~/.config/ryujinx/matugen.xaml'
   ```

3. Generate the palette with Matugen.
4. Select `Matugen` in Ryujinx's User Interface settings. The default path is
   the platform configuration directory's `matugen.xaml`; use Browse to select
   another output path.

Ryujinx does not execute Matugen. When Matugen regenerates the file, Ryujinx
debounces the filesystem events and reloads the palette after it has been fully
written. Invalid or incomplete updates are logged and the previous valid palette
remains active. If no valid palette exists at startup, Ryujinx falls back to Auto.
